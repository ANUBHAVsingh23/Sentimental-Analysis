## Task 4: Sentiment Analysis

### 📌 Overview
This task focuses on **Sentiment Analysis** — the process of identifying and categorizing opinions expressed in text, especially to determine the writer's attitude as positive, negative, or neutral. This is a key task in **Natural Language Processing (NLP)**.

The dataset used in this task primarily relates to social media data, which has been processed and analyzed to extract user sentiments using techniques such as tokenization, stop word removal, and model-based classification.
